# memory-writeback｜記憶回寫與封存

走 `lifeos/000_Agent/02_記憶回寫.md`。

## 回寫

寫進案子檔案底部，最新在最上面：

```markdown
## 記錄

### YYYY-MM-DD
- 狀態：<舊> → <新>
- 做了：
- 卡點：
- 下一步：
```

同時視內容寫到：

| 內容 | 位置 |
|---|---|
| 今天發生什麼 | `lifeos/300_Journal/YYYY-MM/YYYY-MM-DD.md` |
| 三個月後還用得到的知識／範本／對方偏好 | `lifeos/200_Reference/`（私密的放 `private/`） |

**判斷標準：三個月後的我還會需要這句話嗎？**

## 封存

條件：狀態 = `完成` 或 `取消`，**且**最後一筆記錄已寫完。

1. 可重用的東西（範本、話術、清單）**先抽到 `200_Reference/`**
2. 在檔案最上方補結案摘要：

```markdown
> 結案：YYYY-MM-DD｜結果：完成/取消
> 預估 <X> 分 / 實際 <Y> 分
> 下次注意：<一句>
```

3. 移到 `lifeos/900_Archive/YYYY/`（**移動，不是刪除**）
4. 路線 D 的案子額外把時薪換算寫進 `200_Reference/private/報價歷史.md`

## 不要做

- 不要刪檔案
- 不要提早封存還在跑的事
- 封存後不要改內容，要補充就開新檔案連過去
- **取消的事也要回寫取消原因**，這個最容易漏但最有用
