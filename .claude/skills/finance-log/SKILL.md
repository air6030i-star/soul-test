# finance-log｜財務

走 `lifeos/000_Agent/routes/E_財務管理.md`。

> **所有金額資料寫進 `lifeos/200_Reference/private/帳務/YYYY-MM.md`，永不進 git。**

## 記一筆

```markdown
| 日期 | 類型 | 項目 | 金額 | 對象 | 狀態 |
|---|---|---|---|---|---|
| YYYY-MM-DD | 收入/支出 | | | | 待請款/已入帳/已付 |
```

**缺哪欄寫「待補」，不要推算金額。**

## 月結

```
<YYYY-MM> 月結

收入 <X>｜支出 <Y>｜淨額 <Z>

應收未收：
  <對象>｜<金額>｜逾期 <N> 天

訂閱支出合計 <X>，其中本月沒用到：
  <服務>｜<金額>

與上月差異（只列變化 > 20%）：
  <項目>：<上月> → <本月>
```

## 訂閱體檢（每季）

逐項問：這個月用過嗎？有沒有功能重疊的？降級會少什麼？
輸出三欄：**建議取消 / 建議降級 / 保留**。

## 紅線

- **不做稅務、法律判斷。** 只整理資料，結論交給會計師。
- 不自動執行付款、取消、轉帳——只給建議清單。
- 只寫有憑據的金額，一塊錢都不要估。
