# content-draft｜內容草稿

走 `lifeos/000_Agent/routes/C_內容創作.md`。

## 開始前一定要有的三件事

1. 給誰看？
2. 看完要他做什麼？
3. 發在哪個平台？

**缺任何一項就先問，不要先寫再問。**

## 查重

`grep` `lifeos/200_Reference/` 與 `lifeos/900_Archive/`。寫過的主題不重寫，改成更新或延伸，並連回舊文。

## 輸出

```
主標：<主推>
備選：<2 個>

--- 內文 ---
<本體>
---

CTA：<一句>
預估工時：<分鐘>
```

## 送出前自己先跑這個檢查

- [ ] 第一句就有資訊，不是暖場
- [ ] 沒有「其實」「在這個時代」「隨著 AI 的發展」這類填充開頭
- [ ] 有具體的東西：數字、步驟、例子
- [ ] 沒有承諾做不到的事
- [ ] 沒有引用未經查證的外部說法（要引用就附網址與日期）
- [ ] 涉及 Soul Universe → 符合 `lifeos/200_Reference/soul-universe-principles.md`

任何一項沒過，改到過為止再送出。
