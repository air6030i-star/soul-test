# weekly-review｜週回顧

走 `lifeos/000_Agent/routes/A_每週例行.md`。

## Part 1：回顧（看資料，不要憑印象）

從 `lifeos/300_Journal/` 本週檔案 + `lifeos/900_Archive/` 本週封存的案子，統計：

```
本週 <YYYY-MM-DD> ~ <YYYY-MM-DD>

完成：<N> 件    取消：<N> 件    仍在進行：<N> 件
工時：預估 <X> 分 / 實際 <Y> 分（偏差 <±Z>%）

各路線分佈：
  A 例行 <N>｜B 插單 <N>｜C 內容 <N>｜D 接案 <N>｜E 財務 <N>｜F 自有 <N>
```

### 三個要看的訊號

1. **B 插單佔比 > 30%** → 排程被外部綁架，要處理來源
2. **F 自有產品 = 0** → 這週完全沒有為自己做事
3. **實際工時連續超估 30%** → 報價／規劃模型要調

命中就明講，不要包裝。

## Part 2：下週規劃

- 從進行中案子挑出必須推進的（最多 5 件）
- 為 **F・自有產品**保留固定時段（見 `routes/F_自有產品.md`）
- 例行任務對照 `lifeos/200_Reference/例行任務清單.md`
- 連續兩週沒做的例行 → **提出來問要不要砍**

## Part 3：趨勢整理

只在使用者要求時做。查本週與其業務相關的外部變化，**每則附來源網址與日期**，查不到就寫「本週無明確資料」。不要憑印象寫趨勢。

## 輸出

整份是草案，走 `03_草案協定.md`，路線標 `A`。回寫進 `lifeos/300_Journal/`。
