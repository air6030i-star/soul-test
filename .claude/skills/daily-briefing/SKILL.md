# daily-briefing｜開工簡報

## 步驟

1. 掃 `lifeos/100_Todo/projects/` 所有 frontmatter，挑出：
   - `狀態: 進行中` 或 `待開始`
   - `截止` 在 7 天內的
   - `狀態: 等對方` 且超過 3 天沒動的
2. 數 `lifeos/100_Todo/inbox/` 有幾個 `#待分流`
3. 查 `lifeos/200_Reference/例行任務清單.md` 今天該做的例行

## 輸出格式（控制在 15 行內，不要長篇）

```
今天 <YYYY-MM-DD>

先做這一件：
  <案子> — <為什麼是它，一句>

接著：
  2. <案子>
  3. <案子>

等對方（超過 3 天沒動）：
  <案子>｜<幾天>｜建議：追 / 再等 / 放掉

例行：<今天該做的，沒有就寫「今天沒有」>
Inbox：<N> 件待分流
提醒：<一句。沒有就省略這行>
```

## 規則

- **最多列三件**。列太多等於沒列。
- 「先做這一件」一定要給理由，不能只排順序。
- 不要在簡報裡順便把事做掉，這只是簡報。
