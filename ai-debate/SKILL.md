# 雙 AI 會診 Skill

## 核心概念

- 指揮本機**已登入**的兩個 AI CLI，不是串 API：用量分別扣 Claude 與 ChatGPT 的訂閱額度。
- 兩個 AI 不直接互傳訊息。每一輪由主持台（`debate.py`）把「主題＋案件檔案清單＋雙方前面的發言＋主持人插話＋本輪任務」組成提示，送給下一位，形成對話。
- Claude 只開放 `Read / Grep / Glob`；Codex 用 `--sandbox read-only`。原檔只讀不改，產出全部寫在 `<案件資料夾>/_AI會診/`。

## Claude Code 該怎麼用這個 skill

1. 確認兩個指令都已安裝並登入：`claude --version`、`codex --version`（codex 未登入請使用者先執行 `codex login`）。
2. 啟動主持台（會自動開瀏覽器）：
   ```bash
   python ai-debate/debate.py "<案件資料夾>"      # 有案件資料
   python ai-debate/debate.py                    # 純題目討論
   python ai-debate/debate.py --mock             # 不耗額度，先試介面
   ```
3. 告訴使用者網址（預設 http://127.0.0.1:8765/），接下來由使用者在瀏覽器主持。
4. 討論結束後，可讀取 `_AI會診/<場次>/transcript.md` 幫使用者摘要或延伸。

## 會議流程

1. **啟動**：指定案件資料夾（或只給題目）→ 瀏覽器自動開啟會議室。
2. **設定**：選討論方式（12 種）、題目、輪數、先手、誰整合結論、發言長度，可自訂角色；預設勾選「聚焦分歧」。
3. **① 各自分析（閉卷）**：兩方同時讀資料、各自作答，彼此看不到，避免被對方帶著走。
4. **② 互相閱讀**：看對方的答案，列出同意／不同意／對方漏掉的／自己要修正的（會診模式是回原檔做事實核對）。
5. **③ 分歧整理**：由一方擔任中立書記，整理出最多 3 個**實質**分歧，每個分歧都寫出雙方立場、核心假設、需要什麼資料才能判斷。
6. **④ 聚焦討論**：之後每輪只針對這幾個分歧逐點回應，已有共識的不重講；被說服就明說「第 N 點我改變立場」。
7. **⑤ 主持人介入**：隨時插話、補充條件、點名；條件改變時按「🧭 重新整理分歧」。
8. **⑥ 收斂**：兩方寫最終立場，再由一方整合結論（格式見下）。
9. **自動存檔**：每則發言即時寫入 `_AI會診/<場次>/`（`state.json`、`transcript.md`）；首頁「繼續上次議程」可接著討論。

腦力激盪、蘇格拉底詰問、教學問答不需要找分歧，這三種模式會自動跳過步驟 5。

## 不假裝共識

結論整合時一律要求 AI 當「中立書記」而不是裁判：
- 只有雙方都明確同意的才寫成共識，其餘放進「仍有分歧」，兩方立場分開寫、標明是誰。
- 每個分歧都要寫出**造成分歧的核心假設**，以及驗證需要的資料。
- 不寫「綜合兩方意見，建議 A」；改成列出「**需要主持人決定的事**」，以選擇題呈現並說明各選項的代價。

預設結論格式：共同認同／仍有分歧／造成分歧的核心假設／缺乏的資料與建議補查／可立即執行事項／最大風險／需要主持人決定的事。

## 討論方式

| 方式 | 說明 |
|---|---|
| 會診（案件分析）🙈 | 閉卷分析 → 事實核對 → 整理爭點 → 聚焦討論 |
| 自由討論 | 輪流發表、互相補充 |
| 正反辯論 🙈 | 先手正方、後手反方，最後整理雙方最強論點（不判輸贏） |
| 商業評估 🙈 | 一方看市場與收入、一方看成本與風險；檢驗數字與假設，提出最便宜的驗證方式 |
| 執行會議 | 一方拆任務、一方檢查資源與時程；產出任務清單（負責人／期限／完成標準）與本週第一步 |
| 提案＋審查 | 一方提案、一方審查，反覆修正 |
| 腦力激盪 🙈 | 發散接龍 → 收斂前三名 |
| 魔鬼代言人 | 一方主張、一方專門挑戰假設 |
| 蘇格拉底詰問 | 層層追問定義與前提 |
| 共識建構 🙈 | 逐步縮小分歧 |
| 教學問答 | 老師講解、學生追問 |
| 自訂角色 | 自行填兩方角色（如律師 vs 會計師） |

🙈＝開場各自閉卷、同時作答。

## 主持人操作

- **送出插話**：討論中送出 → 下一位發言者優先回應；討論已停 → 送出並自動再討論 N 輪。
- **點名**：指定 Claude 或 ChatGPT 立刻回答你的問題。
- **🧭 重新整理分歧**：補充新條件後，請它們依新條件重新判斷分歧。
- **暫停／繼續**、**再討論 N 輪**、**請下結論**（直接跳到最終立場＋整合）、**結束**、**下載紀錄**。

## 進階設定（環境變數）

| 變數 | 預設 | 用途 |
|---|---|---|
| `DEBATE_CLAUDE_CMD` | `claude -p --output-format text` | 改用其他模型，如加 `--model opus` |
| `DEBATE_CODEX_CMD` | `codex exec` | 如加 `-m gpt-5` |
| `DEBATE_TIMEOUT` | `900` | 單次發言逾時秒數 |
| `DEBATE_PORT` | `8765` | 連接埠（被占用會自動往後找） |
