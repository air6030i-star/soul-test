# 雙 AI 會診 Skill

## 核心概念

- 指揮本機**已登入**的兩個 AI CLI，不是串 API：用量分別扣 Claude 與 ChatGPT 的訂閱額度。
- 兩個 AI 不直接互傳訊息。每一輪由主持台（`debate.py`）把「主題＋案件檔案清單＋雙方前面的發言＋主持人插話＋本輪任務」組成提示，送給下一位，形成對話。
- Claude 只開放 `Read / Grep / Glob`；Codex 用 `--sandbox read-only`。原檔只讀不改，產出全部寫在 `<案件資料夾>/_AI會診/`。

## Claude Code 該怎麼用這個 skill

1. 確認兩個指令都已安裝並登入：`claude --version`、`codex --version`（codex 未登入請使用者先執行 `codex login`）。
2. 啟動主持台（會自動開瀏覽器）：
   ```bash
   python ai-debate/debate.py "<案件資料夾>"      # 有案件資料
   python ai-debate/debate.py                    # 純題目討論
   python ai-debate/debate.py --mock             # 不耗額度，先試介面
   ```
3. 告訴使用者網址（預設 http://127.0.0.1:8765/），接下來由使用者在瀏覽器主持。
4. 討論結束後，可讀取 `_AI會診/<場次>/transcript.md` 幫使用者摘要或延伸。

## 會診流程（預設「會診」方式）

1. **啟動**：指定案件資料夾 → 瀏覽器自動開啟會診畫面。
2. **設定**：選討論方式（10 種）、題目、輪數、先手、誰整合結論、發言長度，可自訂角色。
3. **各自閉卷**：兩方同時讀資料，彼此看不到，避免被對方帶著走；各自產出資料清單、時間軸、事實摘錄、目前狀況、爭點、資料缺口。
4. **事實核對**：互看對方閉卷結果、回原檔查證，抓出誰讀錯、誰漏讀。
5. **議程討論**：每輪兩方輪流回應（先手每輪交替）；主持人隨時插話，下一位會優先回應，也可點名某一方回答。
6. **本段結論**：兩方同時寫最終立場，再由一方中立整合：共識／分歧／待補資料／下一步／風險。
7. **自動存檔**：每則發言即時寫入 `_AI會診/<場次>/`（`state.json`、`transcript.md`）；關閉後再開，首頁「繼續上次議程」可接著提問、再討論。

## 討論方式

| 方式 | 說明 |
|---|---|
| 會診（案件分析）🙈 | 閉卷分析 → 事實核對 → 爭點討論 → 結構化結論 |
| 自由討論 | 輪流發表、互相補充 |
| 正反辯論 🙈 | 先手正方、後手反方，最後中立評審 |
| 提案＋審查 | 一方提案、一方審查，反覆修正 |
| 腦力激盪 🙈 | 發散接龍 → 收斂前三名 |
| 魔鬼代言人 | 一方主張、一方專門挑戰假設 |
| 蘇格拉底詰問 | 層層追問定義與前提 |
| 共識建構 🙈 | 逐步縮小分歧 |
| 教學問答 | 老師講解、學生追問 |
| 自訂角色 | 自行填兩方角色（如律師 vs 會計師） |

🙈＝開場各自閉卷、同時作答。

## 主持人操作

- **送出插話**：討論中送出 → 下一位發言者優先回應；討論已停 → 送出並自動再討論 N 輪。
- **點名**：指定 Claude 或 ChatGPT 立刻回答你的問題。
- **暫停／繼續**、**再討論 N 輪**、**請下結論**（直接跳到最終立場＋整合）、**結束**、**下載紀錄**。

## 進階設定（環境變數）

| 變數 | 預設 | 用途 |
|---|---|---|
| `DEBATE_CLAUDE_CMD` | `claude -p --output-format text` | 改用其他模型，如加 `--model opus` |
| `DEBATE_CODEX_CMD` | `codex exec` | 如加 `-m gpt-5` |
| `DEBATE_TIMEOUT` | `900` | 單次發言逾時秒數 |
| `DEBATE_PORT` | `8765` | 連接埠（被占用會自動往後找） |
