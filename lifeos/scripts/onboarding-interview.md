# 上線訪談（約 10 分鐘）

> 目的：把 `lifeos/000_Agent/00_身份與邊界.md` 裡的「待補」補完。
> 用法：在 Claude Code 或 Codex 說「跑 onboarding 訪談」，agent 照這份一題一題問。

## 給 agent 的規則

- **一次只問一題**，等回答再問下一題。不要一次列 12 題。
- 回答含糊就追問一次，追問完還是含糊 → 寫「待補」，往下走。
- **不要幫使用者填答案**，包括「看起來應該是……」這種推測。
- 全部問完後，產出 `00_身份與邊界.md` 的**修改草案**（走 `03_草案協定.md`），等確認才寫入。

## 題目

### 第一部分：我是誰（3 題）

1. 我希望你怎麼稱呼我？
2. 我的收入來源有哪幾條？請從最重要的排到最不重要。
3. 我一週實際能投入工作的時數大概多少？（不是理想值，是真的）

### 第二部分：事業版圖（3 題）

4. 剛才講的每一條線，各自大概佔你多少時間？佔多少收入？
5. 哪一條線你最想做大？哪一條你其實想收掉？
6. 除了 Soul Universe，還有哪些線需要我認得？（名稱＋一句話說明就好）

### 第三部分：痛點（3 題）

7. 最近一個月，哪一件事讓你覺得「這個如果有人幫我做就好了」？
8. 你最常在哪個環節卡住？（想不出來／拖著不開始／做到一半失焦／收尾收不掉）
9. 有沒有什麼事，就算我做得出來，你也不想交給我？

### 第四部分：協作方式（3 題）

10. 你希望我主動到什麼程度？
    - a 只有你問我才答
    - b 每天給一次簡報，其他時間不吵你
    - c 看到問題就提出來
11. 我給你東西時，你希望先看到結論還是先看到過程？
12. 我做錯的時候，你希望我怎麼講？（直接說 / 先說做對的再說錯的）
