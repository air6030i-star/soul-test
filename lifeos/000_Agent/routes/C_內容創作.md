# C・內容創作

**進入條件**：產出是要對外發佈的內容，且不是特定客戶的交付物。

**典型內容**：社群貼文、長文、電子報、短影音腳本、SEO 頁面、Soul Universe 的行銷文案。

## 步驟

1. **先確認三件事**（缺一就先問，不要開始寫）
   - 給誰看？
   - 看完要他做什麼？（點連結／留言／記住某個概念／什麼都不用做）
   - 發在哪個平台？

2. **查有沒有寫過**
   `grep` 一下 `200_Reference/` 跟 `900_Archive/`。
   重複的主題**不要重寫**，改成更新或延伸，並連回舊的那篇。

3. **產出草案**
   路線標 `C`。草案內容：
   - 主標 + 2 個備選
   - 內文
   - CTA
   - 預估工時

4. **自我檢查**（送出草案前自己先跑一遍）
   - [ ] 第一句話就有資訊，不是暖場
   - [ ] 沒有「其實」「其實我覺得」「在這個時代」這類填充詞
   - [ ] 有具體的東西（數字、步驟、例子），不是只有感受
   - [ ] 沒有承諾我做不到的事
   - [ ] 涉及 Soul Universe 的部分，符合 `200_Reference/soul-universe-principles.md`

5. **我確認後**
   **Agent 不發文。** 產出可直接複製的最終版，由我自己貼上去。

6. **回寫**
   發佈後把最終版存進 `900_Archive/YYYY/`，可重用的句型抽進 `200_Reference/`。

## Soul Universe 相關內容的額外規則

不可以寫：
- 「根據你的命盤，你就是……」這類斷定句
- 恐嚇式話術（不看會怎樣、錯過會如何）
- 歷史人物／老師名字
- 大量裸露類型代碼

要寫成：
- 「你的結果反覆顯示一個可能的傾向……」
- 「你可以看看這是否符合你的真實經驗。」
- 「如果現在的你已經不同，請以現在的自己為準。」
