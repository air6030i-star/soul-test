# F・自有產品／自主專案

**進入條件**：以上皆非。這是我自己的產品、自己想做的事，沒有外部客戶、沒有外部期限。

**典型內容**：Soul Universe 的功能與頁面、新產品線、工具、學習、這套 Life OS 本身。

> 這條路線最容易被 B 跟 D 吃掉時間，所以它需要的不是更多步驟，是**保護**。

## 步驟

### 1. 先寫「不做什麼」

開案子檔案時，除了要做什麼，**一定要寫一行「這次不做什麼」**。
自主專案沒有外部限制，範圍會自己膨脹。

```markdown
本次範圍：把免費結果頁加上「給我的 AI 看」按鈕，可複製、可下載 Markdown
本次不做：AI API 串接、會員系統、付費版、資料庫
```

### 2. 切成可以在一個時段做完的塊

每塊 ≤ 90 分鐘，且**做完就有東西可以看**。
切不出來，代表想得還不夠清楚，先回去想。

### 3. 定驗證條件

自主專案最大的風險是做完了不知道有沒有用。開始前先寫：

```markdown
做完之後，我要看什麼數字來判斷它值不值得繼續？
→ 待補
```

寫不出來的專案，先不要做。

### 4. 產出草案 → 我確認 → 執行

路線標 `F`。

### 5. 回寫

實際工時 vs 預估，以及**驗證條件的結果**。

## 這條路線的常見錯誤

- 沒有期限所以無限期拖 → **排進 A・每週例行 的固定時段**，用例行保護它
- 範圍膨脹 → 回頭看第 1 步寫的「不做什麼」
- 做完沒驗證就接著做下一個 → 第 3 步的數字要真的去看
